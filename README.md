# 避雷王翀！！

## 小组贡献第二，最后分数77！


本课程存在以下几个问题。

1. 教学内容与实践脱节。
   课程大量时间围绕纯理论内容展开，真正用于课程知识讲授的时间较少，与课程目标关联性不足，学生整体收获有限。

2. 对技术前沿关注不足。
   课程内容更新较慢，对近年来广泛应用的大语言模型（LLM）等技术缺乏介绍，课堂上甚至带有明显否定态度，导致学生难以接触当前行业的发展方向。希望课程能够以客观、中立的态度介绍新技术，并引导学生分析其优势、局限和适用场景，而不是简单否定。

3. 课程负担与收益不匹配。
   课程安排的小组作业工作量较大，但教师指导较少，学生投入大量时间完成任务，与课堂教学支持不成比例。

4. 小组作业评分缺乏透明性和公平性。
   本次小组作业中，我承担了较多开发工作，GitHub 提交记录和代码贡献均可客观证明我的贡献处于小组前列，但最终成绩却处于组内最低，没有得到任何评分依据或解释。这使我对评分标准和评价过程产生疑问。建议今后公开评分细则，并结合代码提交记录、任务分工、答辩表现等客观依据进行综合评价，提高评分的公平性和透明度。
